How to use it · tool guide
TASK_GUIDE, a TypeScript string in the tool description. Not a .md.
"Code tasks: to change or complete a code task, find it in <in_progress> and pass its number as task. In the conversation where it was asked, it is automatic. If two tasks may match, ask which one. A new, unrelated piece of work: new: true."
The link to a task is code, not memory. The session itself is prompted with prompts/persona.md + code-task.md (+ code-task-terminal.md with the workshop): see Prompts and files.

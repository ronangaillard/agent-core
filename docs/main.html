Steve — agent-core architecture
Implemented in agent-core (github.com/ronangaillard/agent-core), running on the NAS since 2026-11-14. Every input carries an opaque Address (connector, conversation, thread, ts); the core carries it without reading it. SQLite: inbox and outbox hold the state (status), events keeps the append-only history; every status transition writes its event in the same transaction. No polling.

Prompts and files

Every text the agent is prompted with is a Markdown file in prompts/ (AGENT_PROMPTS), written with its default when missing and read again at every use: an edit applies at the next message, no restart. Blue: a prompt file. Grey: data built by code. Orange: the memory. Tool descriptions stay in the code: they describe what the code does.
